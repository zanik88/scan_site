# 🛡️ Компонент-Эксперт

**Платформа автоматизированного аудита ПО на соответствие ПП РФ № 1236**

Веб-сервис для экспертов, разработчиков и интеграторов, который анализирует зависимости ПО, выявляет запрещённые компоненты, проверяет уязвимости (CVE) и формирует вердикт о возможности включения в Единый реестр российских программ.

## ✨ Возможности

- 📂 **Парсинг 5+ форматов:** `requirements.txt`, `package.json`, SBOM (CycloneDX/SPDX), Excel, Word, PDF.
- 🐳 **Docker-сканер:** автоматический анализ базовой ОС и установленных пакетов.
- 🤖 **ИИ-анализ:** GigaChat (с OAuth) — определение лицензий для неизвестных компонентов.
- ⚡ **Кэш ИИ-ответов:** экономия запросов к API (TTL 90 дней).
- 🔒 **Проверка CVE:** через открытый OSV API (Google).
- ⚖️ **ПП РФ № 1236:** полная база правил из официальной таблицы Минцифры.
- 🇷🇺 **Российские аналоги:** Astra Linux, ALT Linux, Postgres Pro, Liberica JDK.
- 📊 **13 категорий компонентов** с фильтрами и поиском.
- 📥 **Экспорт в Excel** с колонками CVE и категориями.
- 👥 **Мультипользовательский режим:** тарифы Free/Pro, админ-панель.
- 🛡️ **Rate Limiting:** защита от спама (5/мин на `/upload` для гостей).
- 💾 **Резервное копирование:** cron-задача + скрипт восстановления.

## 🚀 Быстрый старт

### Требования

- Docker 24+
- Docker Compose v2
- Linux-сервер (Ubuntu 22.04 / Astra Linux / Alt Linux)
- Свободный порт 8080

### Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/zanik88/scan_site.git
cd scan_site

# 2. Настроить переменные окружения
cp .env.example .env
nano .env

# 3. Запустить
docker compose up -d --build
Сервис будет доступен на http://localhost:8080.

Переменные окружения (.env)
Переменная	Описание	Обязательно
SECRET_KEY	Секретный ключ для сессий (мин. 32 символа)	✅ Да
COOKIE_SECURE	true если работает HTTPS, иначе false	✅ Да
DATABASE_URL	Путь к SQLite-базе	Нет
GIGACHAT_API_KEY	Authorization Key из GigaChat Studio	Опционально
YANDEX_GPT_API_KEY	API-ключ YandexGPT	Опционально
YANDEX_FOLDER_ID	ID каталога Yandex Cloud	Опционально
📖 Использование
Способ 1: Загрузка файла
Перетащите файл с зависимостями. Поддерживаются:

.txt — имя==версия

.json — SBOM (CycloneDX/SPDX) или package.json

.xlsx, .xls — Excel-выгрузки

.docx — Word-документы

.pdf — PDF-манифесты

Способ 2: Ввод текста
Вставьте список вручную:

text
fastapi==0.115.6

Способ 3: Сканирование Docker-образа
Введите имя образа: python:3.12-slim. Сервис поднимет контейнер, определит базовую ОС и проанализирует пакеты.

🧠 Как работает анализ
Парсинг — извлекаем компоненты из файла.

База знаний — сверяем с 250+ правилами.

Хардкод-проверки — критичные (DevExpress, IBM DB2, Splunk) проверяются раньше всех.

Кэш ИИ — если компонент уже проверялся, берём ответ из БД.

ИИ-анализ — GigaChat определяет лицензию для неизвестных.

Проверка CVE — через OSV API.

Категоризация — 13 категорий.

Вердикт — по количеству запрещённых и требующих внимания.

Специальные случаи
Unity / Unreal Engine — «Требует внимания» с ссылкой на письмо Минцифры от 21.08.2023 № АЗ-П11-4-200-216747.

Java (OpenJDK) — рекомендация перейти на Liberica / Axiom / Динамика JDK.

Redis 7.4+ / MongoDB — рекомендация заменить на Valkey / Postgres Pro.

Oracle MySQL Community — разрешено (GPL), Enterprise — запрещено.

DevExpress — полный запрет (экспортные ограничения).
