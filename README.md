# Компонент-Эксперт — Платформа аудита ПО (ПП РФ № 1236)

Веб-сервис для автоматизированного аудита зависимостей ПО на соответствие требованиям Единого реестра российского ПО.

## Возможности
- Анализ зависимостей (requirements.txt, package.json, SBOM)
- Docker-сканер образов
- ИИ-экспертиза (YandexGPT / GigaChat)
- Экспорт отчётов в Excel
- Форма обратной связи

## Запуск
```bash
cp .env.example .env
docker compose up --build -d
