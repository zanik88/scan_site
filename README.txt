Веб-сервис для аудита ПО и анализа лицензий
Этот проект представляет собой веб-сервис на базе FastAPI для автоматизированного аудита программного обеспечения, анализа программных лицензий компонентов (на предмет конфликтов и соответствия требованиям реестра отечественного ПО) и генерации отчетов.
🛠 Технологии
Backend: Python, FastAPI
База данных: PostgreSQL
Инфраструктура: Docker, Docker Compose
Frontend: JS / HTML
🚀 Основной функционал
Анализ зависимостей: Загрузка файлов манифестов (requirements.txt, package.json и др.) или указание URL для парсинга.
Проверка лицензий: Автоматическое определение лицензий (MIT, GPL, Apache и др.) для каждого компонента и выявление конфликтов.
Хранение истории: Все результаты проверок и сгенерированные отчеты сохраняются в БД PostgreSQL для последующего просмотра.
Генерация отчетов: Автоматическое формирование сводных отчетов по результатам аудита с подсветкой проблемных компонентов.
⚙️ Запуск проекта
Для запуска сервиса вам потребуется установленный Docker и Docker Compose.

Склонируйте репозиторий и перейдите в корневую папку с проектом.
Выполните команду для сборки и запуска контейнеров:

docker-compose up --build

После успешного запуска сервис будет доступен по следующим адресам:
Интерактивная документация API (Swagger UI): http://localhost:8000/docs
🤖 Особенности разработки
Проект разработан с применением современных практик асинхронного программирования (asyncio), строгой валидации данных (Pydantic) и контейнеризации. Логика проверок вынесена в изолированные модули для удобства тестирования и масштабирования.
📁 Структура проекта
├── app/
│   ├── main.py          # Точка входа FastAPI-приложения
│   ├── api/             # API эндпоинты (роутеры)
│   ├── core/            # Настройки и конфигурация (в т.ч. загрузка .env)
│   ├── models/          # ORM модели базы данных
│   ├── schemas/         # Pydantic модели (схемы валидации)
│   ├── services/        # Бизнес-логика (аудит, парсинг, генерация отчетов)
│   └── tests/           # Автоматические тесты
├── docker-compose.yml   # Настройки мультиконтейнерного запуска
├── Dockerfile           # Инструкции по сборке образа backend-части
├── requirements.txt     # Файл с зависимостями Python
└── .env.example         # Пример файла с переменными окружения
🔐 Переменные окружения (.env)
Перед запуском проекта создайте файл .env в корневой директории (рядом с docker-compose.yml). Вы можете скопировать структуру из .env.example. 
Пример содержимого файла .env:
# Настройки базы данных PostgreSQL
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_secure_password
POSTGRES_DB=audit_db
POSTGRES_HOST=db
POSTGRES_PORT=5432

# Строка подключения для SQLAlchemy / SQLModel
DATABASE_URL=postgresql://postgres:your_secure_password@db:5432/audit_db
